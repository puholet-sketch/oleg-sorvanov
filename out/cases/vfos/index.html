Кейс · VFOS · партнёрский канал · Росгосстрах / БПБ

VFOS · виртуальный фронт-офис продаж

Платформа автоматизации продажи страховых продуктов партнёрами заказчика через интернет: браузерный портал и Product API. Virtu Systems поддерживает и развивает систему для ПАО СК «Росгосстрах» (блок партнёрского бизнеса).

Назначение

На рабочем месте продавца партнёра достаточно браузера. Система обеспечивает расчёт, оформление, печать и обмен с учётными системами РГС. Крупные партнёры оформляют из своего ПО через API VFOS без обязательного входа в экраны портала.

Клиент и роль Virtu

  • Заказчик — ПАО СК «Росгосстрах», БПБ (блок партнёрского бизнеса)
  • Virtu Systems — разработчик и сопровождение платформы
  • Покрытие: БПБ ЦО и региональная сеть, БМС, БКС
  • Куратор РГС сопровождает пул партнёров; IT-контур — на стороне Virtu

Возможности

  • Оформление, выпуск и печать полисов (БСО / бумага / PDF) + пакет документов
  • Автоматический расчёт премии, управление тарифами и продуктами
  • Портал продаж: формы, автозаполнение, поиск договоров, аннулирование, массовая печать
  • Product API для банков, автосалонов, сетей, МФО
  • Выгрузка в учёт (UXML / ЕКИС и смежные контуры)
  • Мониторинг продаж и аномалий; отчёты и бордеро
  • Интернет-эквайринг, электронная квитанция, загрузчик Excel → VFOS → ЕКИС
  • Админ-панель: оргструктура, пользователи, продукты, тарифы, справочники

Продуктовая линейка

ОСАГО, КАСКО, ДМС, НС, имущество и коробки, ВЗР, GAP, продлённая гарантия, мобильная защита, автофорсаж и банковские продукты партнёрского канала.

Каналы и сценарии

  • Автосалоны и дилеры — ОСАГО с кроссом в КАСКО на точке
  • Салоны связи и федеральные сети — коробки / гарантия
  • Банки и МФО — портал или оформление из своего ПО по API
  • Офисы РГС — единый фронт партнёрских продаж

Архитектура

Клиент (браузер) → FrontOffice (ASP.NET WebForms, IIS) → бизнес-модули продуктов и интеграций → сервисы .NET Core → MS SQL (dbRGS) + Redis. Админ-панель — отдельное PHP/Yii2 приложение. Auth: Keycloak / Kerberos/LDAP, роли через группы домена. Масштабирование: NLB веб, кластер SQL с репликацией на чтение.

Интеграции

  • ЕКИС, КИАС, CDI, GWPC, UFO, FileStore
  • СКК, ТКБ, Check_BSO и смежные контуры оплаты/бланков
  • Сервисы: SalesMonitoring, ReportSender, PolicyWriter, ReverseProxy, Underwriting…

Сопровождение и развитие

Платформа в постоянной промышленной эксплуатации: развитие продуктовой линейки и API, стабилизация интеграций с контуром РГС, релизы и поддержка партнёрского канала под управлением проектного офиса Virtu.
