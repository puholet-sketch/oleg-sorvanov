Кейс · ОФР / ЛК Агента · Росгосстрах

ЛК Агента · контрактное оформление коробочных продуктов

ОФР / ЛКП — кабинет продавца-партнёра ПАО СК «Росгосстрах» для оформления коробочных продуктов: от анкеты и расчёта до договора в Guidewire, оплаты и печати полиса. Host ЛКП + продуктовые микрофронтенды + BFF.

Задача

Один браузерный канал для продавцов партнёра (агент, МАГ и др.): много коробочных продуктов, разные правила оформления, общие платежи, печать и права — без отдельного «тонкого клиента» под каждый продукт.

Решение

ОФР и контур «Контракты»: ofr-core как shell личного кабинета агента (ЛКП), продуктовые микрофронтенды (Module Federation), BFF поверх Guidewire PC, SCC, CDI, платёжных и документных сервисов.

Сценарий оформления

  • Анкета / wizard по продукту (микрофронтенд)
  • Сохранение formData (declaration / submission) в Guidewire
  • Расчёт премии и проверка условий (конфиг + SCC)
  • Поиск клиента и подсказки (CDI, MS Clients)
  • Оплата: счета, ссылки, СБП; создание и выпуск полиса
  • Печать / выдача документов (FileStore, PDF)

Каталог продуктов

  • Авто: помощь на дороге, КАСКО.Профессионал, защита от бесполисных
  • ИФЛ: квартира/дом (фундамент и в деталях), расторжение, отмена
  • Жизнь / здоровье: доктор онлайн, НС, иммунитет, клещ, терапия…
  • Прочее: ипотека онлайн, travel «Поехали 2.0»
  • Сервисные МФ: оплата и рассрочка

Возможности платформы

  • Пролонгация, расторжение, отмена, техкоррекция
  • Задачи согласования / андеррайтинга (GW / MS Tasks)
  • Роли и fine-grained права (Rights BFF, feature flags)
  • Общие UI-libs, Zod/RHF, единый UX продавца
  • Observability: Splunk, Prometheus, business logs

Роли продавцов

Агент, МАГ, МОП, МВС, НСО, тер. директор, ЗДРС, директор филиала, ЗДир РПП — роль из Core/Rights BFF, доп. маппинг из Pulse/ZUP.

Архитектура

Продавец → ofr-core (host ЛКП) → продуктовый МФ → BFF → Guidewire PC / SCC / CDI / КИАС / FileStore / платежи. Стек: React 18 + TypeScript + Redux Toolkit + Module Federation; Express/TS BFF; PostgreSQL + Redis.

Интеграции

  • Guidewire PolicyCenter — declarations, submissions, contracts, invoices
  • SCC — продуктовые и технические справочники
  • CDI / hints, MS Clients — клиент и адреса
  • КИАС / BSO, FileStore, MS Communications
  • Vehicle Aggregator, Resolute, Pulse/ZUP, Contract Log

Роль проектного офиса

В портфеле delivery ВИРТУ: развитие и сопровождение контура ЛК Агента для заказчика, координация продуктовых МФ, интеграций и стабилизации поставок в промышленную эксплуатацию.
